## Что где живёт

| Уровень | Где лежит | Кто владеет |
|---------|-----------|-------------|
| Файлы репозитория (`LICENSE`, `README.md`, этот файл, `.gitignore`) | корень репозитория | пользователь |
| Правила проекта, процесс, архитектура | внутри проекта: `AGENTS.md`, `WORKFLOW.md`, `ARCHITECTURE.md`, `docs/` | архитектор проекта |
| Код, инфраструктура, пайплайн | внутри проекта | работа над проектом |
| Состояние проекта между сессиями | внутри проекта: `memory-bank/` | архитектор проекта |
| Общие правила для всех проектов (git, референс-репозитории, роли) | `~/.dsh/AGENTS.md` — вне репозитория | пользователь |

## Правила границ

- Каждый проект собирается, тестируется и деплоится **самостоятельно**: без сборки и импортов из соседних проектов.
- Абсолютные machine-local пути и ссылки на другие проекты в коде и конфигурации недопустимы.
- Секреты — в `.env` внутри проекта (файл в `.gitignore`) или в переменных окружения; в репозиторий не попадают.
- `LICENSE` и `README.md` репозитория проекты не меняют.
- Новые каталоги верхнего уровня создаются только по решению пользователя.
- Правила проекта не дублируют общие правила: общее — в `~/.dsh/AGENTS.md`, проектное — внутри проекта.

---

## Пайплайн работы

1. Пользователь ставит задачу и создаёт ветку (`develop` — рабочая, `feature/*`, `fix/*`, `chore/*`).
2. Агент выполняет работу внутри проекта: правит файлы, но **git-операции не выполняет**
   (жёсткое ограничение — `~/.dsh/AGENTS.md` §11).
3. Пользователь проверяет diff, коммитит и пушит сам.

## 5. Контракты и форматы данных

### Тестовые швы

- `IWeatherProvider` — HTTP подменяется **заглушкой `HttpMessageHandler`**, реальная сеть
  запрещена. `OpenMeteoWeatherProvider` берёт клиент из `IHttpClientFactory` — в тесте
  подставляется заглушка фабрики, отдающая `HttpClient` с этим обработчиком.
- `WeatherDigestService` принимает `IWeatherProvider`, `IWeatherFormatter`, `ITelegramSender`,
  `IBotStateManager` — все четыре подменяются через NSubstitute.
- `DiCompositionTests` собирает **настоящую** коллекцию сервисов и проверяет резолв.

### Что обязательно покрыть — провайдер

- **успех**: эталонный JSON из постановки `01-01` §2 → корректный `WeatherInfo`, включая
  `ObservedAt` со смещением из `utc_offset_seconds`, и давление, переведённое в мм рт.ст.;
- **не-200** (например, 500) → `Result.Failure`;
- **таймаут** (`TaskCanceledException` без отмены токена) → `Result.Failure`;
- **битый JSON** → `Result.Failure`;
- **ответ без блока `current`** → `Result.Failure`;
- **неразбираемое или отсутствующее `time`** → `Result.Failure`, не исключение;
- в сформированном запросе присутствуют `wind_speed_unit=ms` и `timezone=auto`
  (проверяется по URI запроса);
- ни один из этих путей **не выбрасывает** исключение наружу.

### Что обязательно покрыть — оркестратор

- успех: погода получена → текст отформатирован → сообщение отправлено → `MarkSent` вызван,
  результат успешный;
- погода не получена → отправки нет, результат — ошибка провайдера;
- Telegram отклонил → результат — ошибка отправки, `MarkSent` **не** вызван;
- одновременные вызовы не приводят к наложению отправок (проверить, что отправка происходит
  по одному разу).

### Что обязательно покрыть — композиция DI

Собрать `ServiceCollection`, вызвать `AddInfrastructure` с конфигурацией, собрать
`ServiceProvider` и убедиться, что **резолвятся**: `IWeatherProvider`, `IWeatherFormatter`,
`ITelegramSender`, `IBotStateManager`, `ILogBuffer`, `IHttpClientFactory`.

Почему это обязательно: компилятор не ловит незарегистрированную зависимость. В `01-01`
`IHttpClientFactory` оставался незарегистрированным при полностью зелёной сборке, и дефект был
виден только при резолве.

Конфигурация берётся через `ConfigurationBuilder` (в проекте ArchitectureTests доступен
транзитивно через ссылку на `WeatherBot.Web`); пустая конфигурация допустима — настройки
получат значения по умолчанию.

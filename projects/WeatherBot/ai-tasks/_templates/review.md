## Проверка качества кода

- [ ] Слои и направление зависимостей не нарушены (`Web → Infrastructure → Application → Domain`).
- [ ] Паттерны проекта соблюдены: Result Pattern, абстракции в Application, реализации
      в Infrastructure, Domain — только BCL.
- [ ] Ошибки не покидают инфраструктуру: реализации `ITelegramSender` / `IWeatherProvider`
      возвращают `Result.Failure(...)`.
- [ ] Нет следов БД, ORM, миграций, фронтенда и Docker.
- [ ] Нет дублей, magic strings, «абстракций на будущее».
- [ ] Обработка ошибок явная, без проглоченных исключений.
- [ ] Безопасность: нет секретов в коде и логах, внешние вызовы с таймаутами, маскировка
      через `SecretMasker`.
- [ ] Тесты проверяют поведение и детерминированы, без сетевых вызовов.

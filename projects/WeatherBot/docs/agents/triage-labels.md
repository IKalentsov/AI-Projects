# Triage labels

Скиллы говорят на пяти канонических ролях триажа. Здесь — какие строки им соответствуют
в этом проекте.

| Роль в mattpocock/skills | Строка в нашем трекере | Значение |
| ------------------------ | ---------------------- | -------- |
| `needs-triage` | `needs-triage` | Нужно решение архитектора: что это и что с этим делать |
| `needs-info` | `needs-info` | Ждём информации от постановщика |
| `ready-for-agent` | `ready-for-agent` | Полностью описан, можно отдавать исполнителю |
| `ready-for-human` | `ready-for-human` | Требует человека (доступы, сеть, запуск проекта) |
| `wontfix` | `wontfix` | Решено не делать |

В локальном трекере роль записывается строкой `**Status:**` в начале файла тикета.

Когда скилл просит «apply the AFK-ready triage label», ставится `ready-for-agent`.

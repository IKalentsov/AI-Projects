## Вердикт

**ОК (после доработок).** Приёмка пройдена и **перепроверена мной**: сборка `Ошибок: 0` /
`Предупреждений: 0`, `WeatherBot.UnitTests.dll` — `всего: 89, сбой: 0`,
`WeatherBot.ArchitectureTests.dll` — `всего: 6, сбой: 0`. Тесты содержательные, в сеть не выходят,
JSON-фикстуры повторяют реальный формат Open-Meteo.

**Главный результат тикета — не тесты, а найденный продовый дефект.** Ответ Open-Meteo
**никогда не разбирался**: свойства контракта в PascalCase, API отдаёт snake_case, а
`JsonSerializerDefaults.Web` snake_case не мапит. `time` — слово из одного слова, оно биндилось,
поэтому провайдер не падал, а **молча возвращал нули** по всем остальным полям: 0 °C, 0 % влажности,
«ясно», ветер 0, смещение 0. Дефект жил с `01-01` и был не виден ни ревью, ни живому запуску.
Исполнитель нашёл его, исправил `[JsonPropertyName]`-атрибутами и честно объявил в отчёте §3.
Именно ради такого класса ошибок тикет и требовал тест на разбор ответа.

### Обоснования `reject`

1. **Замечание 10** отклоняется: исполнитель не мог использовать `AwesomeAssertions`, не нарушив
   запрет на правку `csproj`, и объявил выбор в отчёте. Вопрос единого стиля ассертов выносится
   пользователю отдельно.
2. **Претензия к исполнителю по замечанию 2** отклоняется: изменение `src` он не скрыл, а объявил
   в §3 отчёта с обоснованием; без него тесты не проходили бы, и это была правда. Ошибка — в
   критерии приёмки, который написал архитектор.

### Отложено (`defer`)

1. Единый стиль ассертов (`AwesomeAssertions` в архитектурных тестах) — отдельное решение
   пользователя: тянет правку `Directory.Packages.props` и `csproj`.
2. Проверка времени прогона (`60 с`) как требования к следующим тикетам — после правки замечания 5
   имеет смысл зафиксировать ориентир «весь прогон unit-тестов < 5 с».

## Уточнение по замечанию 3 (решение пользователя, 2026-09-22)

Подавления решено **убрать полностью**, а не сужать. Основание — проверенные факты:

- `CS4014` лечится `await` на строках проверки вызовов. Ожидать безопасно: NSubstitute для
  `Task`-возвращающих методов отдаёт уже завершённую задачу (в сборке `nsubstitute/6.2.0`
  присутствуют `NSubstitute.Routing.AutoValues`, `AutoValueBehaviour` и кэшированный делегат
  `CompletedTask`). Возвращаемое значение — автоматическое, не из `Returns(...)`; использовать
  его нельзя, ожидать можно.
- `xUnit1051` — правило анализатора `xunit.analyzers/1.18.0`: «Calls to methods which accept
  CancellationToken should use `TestContext.Current.CancellationToken` to allow test cancellation
  to be more responsive». Есть автоисправление `xUnit1051_UseCancellationTokenArgument`; в наших
  тестах лечится заменой `TestCt = CancellationToken.None` на `TestContext.Current.CancellationToken`.

корректности — сборка `0/0` **без** `#pragma`.

# Глоссарий

**Последнее обновление:** 2026-09-10

Правило: в коде используются английские термины (вторая колонка), в общении и документации —
русские. Один термин — одно значение: если смысл расходится, термин переименовывается,
а не «уточняется по контексту».

## Домен

| Русский | English (код) | Значение |
|---------|---------------|----------|
| Поисковый запрос | `SearchQuery` | Свободный текст пользователя плюс применённые критерии и фильтры |
| Критерий | `Criterion` | Проверяемое требование к товару/продавцу/предложению |
| Набор критериев | `CriteriaSet` | Именованный набор критериев для категории товаров |
| Предложение | `Offer` | Товар конкретного продавца на конкретном маркетплейсе |
| Товар | `Product` | Номенклатурная единица (может встречаться у разных продавцов) |
| Продавец | `Seller` | Поставщик/продавец на маркетплейсе |
| Маркетплейс | `Marketplace` | Площадка-источник (Ozon, WB, Яндекс.Маркет, ВкусВилл) |
| Оценка доверия | `TrustScore` | Числовая/категориальная оценка надёжности |
| Вердикт проверки | `Verdict` | Результат проверки предложения по критериям: прошло/не прошло и почему |
| Источник данных | `DataProvider` | Адаптер к API/MCP/парсеру площадки |
| Снимок | `Snapshot` | Сохранённое состояние карточки на момент времени |
| История цены | `PriceHistory` | Ряд значений цены по времени |
| Поставщик (норматив) | `Regulation` | Нормативное требование (ГОСТ/ТР ТС/РосКонтроль) |

## Технические

| Русский | English (код) | Значение |
|---------|---------------|----------|
| Вариант использования | `UseCase` / `Handler` | Сценарий бизнес-операции в слое Core |
| Контракт | `Contract` / `Dto` | DTO и интерфейсы, публичные для слоёв и API |
| Агрегат | `Aggregate` | Кластер сущностей с единым инвариантом |
| Объект-значение | `ValueObject` | Неизменяемый типизированный примитив (`Price`, `Slug`) |
| Результат | `Result<T>` | Успех или типизированная ошибка (без исключений для бизнес-правил) |
| Миграция | `Migration` | Версионированное изменение схемы БД |
| Снапшот модели | `ModelSnapshot` | Служебный файл EF Core |
| Наблюдаемость | `Observability` | Логи, метрики, трассировки |
| Готовность | `Readiness` | Готовность сервиса принимать трафик (`/health/ready`) |
| Живость | `Liveness` | Признак, что процесс жив (`/health/live`) |

## Соглашения об именовании (код)

- Сущности: `Product`, `Offer`, `Seller` — существительное в единственном числе.
- Value Objects: `Price`, `Rating`, `ProductUrl` — без суффикса `ValueObject`.
- DTO: суффикс `Dto` (`SearchRequestDto`, `OfferDto`).
- Обработчики: суффикс `Handler` (`SearchOffersQueryHandler`).
- Валидаторы: суффикс `Validator` (`SearchRequestValidator`).
- Репозитории: интерфейс `IOffersRepository`, реализация `OffersRepository`
  (или `NpgsqlOffersRepository` для Dapper-варианта).
- Таблицы и колонки БД — `snake_case` (`offers`, `trust_score`, `create_at`).

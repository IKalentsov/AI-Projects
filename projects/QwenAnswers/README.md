# QwenAnswers

Консольное приложение для чата с AI-моделью через OpenAI-совместимый API.

## Что это

Простой чат-клиент, который подключается к локальному серверу LLM (например, Ollama, vLLM, LM Studio) по протоколу OpenAI и ведёт диалог с моделью, сохраняя контекст беседы.

Поддерживает любые модели, которые предоставляют OpenAI-совместимый API: Qwen, Llama, Mistral и другие.

## Быстрый старт

### 1. Настройка конфигурации

Скопируйте шаблон конфигурации:

```bash
copy .env-public .env
```

Откройте файл `.env` и заполните три параметра:

| Параметр | Описание | Пример |
|---|---|---|
| `AI_API_KEY` | API-ключ для доступа к серверу. Если сервер не требует ключ — напишите любое значение, например `ollama` | `sk-your-key-here` |
| `AI_ENDPOINT` | URL вашего AI-сервера с путём к `/v1` | `http://localhost:8080/v1` |
| `AI_MODEL_NAME` | Имя модели, которая запущена на сервере | `unsloth/Qwen3.6-35B-A3B-MTP-GGUF` |

**Файл `.env` не попадает в git** — он создан специально для ваших локальных настроек и хранит их в секрете.

### 2. Запуск

```bash
dotnet run
```

### 3. Использование

Введите сообщение и нажмите Enter. Для выхода введите `exit` или `quit`.

```
Чат с моделью unsloth/Qwen3.6-35B-A3B-MTP-GGUF. Введите 'exit' для выхода.

Вы: Привет, как дела?
AI: Привет! Я здесь, готов помогать. Чем могу быть полезен?

Вы:
```

## Структура файлов

| Файл | Назначение |
|---|---|
| `.env` | **Ваши** секретные настройки (не коммитится в git) |
| `.env-public` | Шаблон с пустыми значениями — для копирования и ознакомления |
| `.gitignore` | Правила, исключающие `.env` из git |
| `Program.cs` | Исходный код приложения |
| `QwenAnswers.csproj` | Проект .NET 10.0 |

## Технические детали

- **.NET 10.0**, C# последний
- **Microsoft.Extensions.AI** — абстракция над AI-клиентами
- **OpenAI** SDK — для совместимости с OpenAI-протоколом
- Простой парсер `.env` без внешних зависимостей
- Контекст диалога сохраняется в памяти (список сообщений)

## Troubleshooting

**"Ошибка: файл .env не найден"** — скопируйте `.env-public` в `.env` и заполните данные.

**"Ошибка: в .env не заполнены все поля"** — проверьте что все три параметра (`AI_API_KEY`, `AI_ENDPOINT`, `AI_MODEL_NAME`) имеют непустые значения.

**"Connection refused"** — убедитесь что AI-сервер запущен и доступен по указанному `AI_ENDPOINT`.

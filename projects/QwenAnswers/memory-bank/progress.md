# Progress

## Работает
- Чтение `.env` при старте (+ понятная ошибка, если файл занят или недоступен)
- Валидация настроек: список всех проблем сразу, отдельная подсказка для неотредактированного шаблона
- Подключение к AI-серверу по OpenAI-протоколу
- Однопоточный последовательный чат: ввод → AI (блокировка) → ответ
- Отмена запроса по Esc; после отмены чат продолжает работать
- Корректная обработка ошибок и таймаута (try-catch, `ChatResult`)
- Выход по `exit` / `quit` и по концу ввода (EOF)
- **IChatClient disposed через `using var`**
- Сборка: 0 ошибок, 0 предупреждений проекта и тестов

## Тесты
- `Unit/` — разбор `.env`, валидация, история, сессия, сборка клиента, консольный цикл, клавиши
- `Integration/` — готовность вашего `.env` (категория `Readiness`), секреты не в git, живые запросы (`Live`)
- `Architecture/` — шаблон, `.gitignore`, README, `.csproj`, решение
- Живые тесты включаются флагом `AI_RUN_LIVE_TESTS=1`, иначе помечаются как `Skipped`
